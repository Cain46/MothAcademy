# Moth Academy · Paleta oficial V1

- Deep Navy — `#06111A` — fondo principal.
- Surface Navy — `#0B2136` — tarjetas, sidebar y superficies.
- Secondary Navy — `#102B45` — estados hover y superficies elevadas.
- Moth Gold — `#D5A641` — color de marca y acento principal.
- Light Gold — `#F0D38A` — títulos destacados y elementos de énfasis.
- Ivory — `#F5F1E8` — texto principal sobre fondo oscuro.
- Muted Steel — `#A7B2BF` — texto secundario.
- Success — `#49C584` — módulo repasado / guardado.
- Danger — `#E66A6A` — reinicios o acciones destructivas.

## Regla visual
La identidad se apoya en Deep Navy + Moth Gold. El dorado debe funcionar como acento, no como fondo dominante. Ivory se usa para lectura prolongada y Muted Steel para información secundaria.
