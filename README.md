# Moth Academy

**Aprender · Practicar · Evolucionar**

Aplicación web estática de estudio y repaso de Quality Assurance.

- Sin login.
- Sin notas.
- Sin backend.
- El progreso y las respuestas se guardan localmente en el navegador.
- El usuario puede exportar e importar su progreso en JSON.

Preparada para GitHub Pages desde la rama `main`.
